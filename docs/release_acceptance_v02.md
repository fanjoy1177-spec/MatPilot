## 真实 DeepSeek 调用

实际宿主为 Harness Desktop 0.2.1-rc.2，deepseek-flash，关闭思考模式。三个开发可见提示在修复前后各测一轮；没有隐藏测试集、独立评分或 U+ 对照。

| 提示 | 修复前 | 修复后 |
|---|---|---|
| 登记模板、NaCl、空间群221、最多2次、等确认 | 引文位置错误，多次计划失败；无提交 | 第一份计划仍含错误字段，工具拦截；模型自行修正后就绪，经测试会话确认后完成演示和报告 |
| Fe-Ni-O 与带隙2 eV 同时作为条件、不可删减 | 查能力后拒绝，无提交 | 查能力后拒绝，无提交；没有把不兼容条件静默删掉 |
| 带隙目标1200 meV、最多2次、只计划 | 引文位置及定性字段错误，计划失败 | 首次计划就绪，归一化1.2 eV，原值与单位保留，无提交 |

修复是在工具层加入唯一精确引文定位、补全每种需求的字段与 relation 说明。显式位置错误、重复引文、虚构单位和预算扩大仍拦截。工作流指令完整保留在原文，由宿主与后端策略处理，不能声称需求表对任意工作流语言作了语义证明。

全部六次案例和每次 prepare_plan 失败见 [真实 API 记录](../artifacts/v03-live-acceptance.json)。修复前 11 次 API 调用，修复后 14 次；前者未跑通全流程，不能用这个调用数作效率比较。

仍有回答措辞局限：联合条件冲突后，模型提出后验筛选建议，但未再次明确当前没有带隙评价器。该建议没有执行，也没有报告虚构性质；仍不能把这一轮算作经独立判定的完整科研正确性成绩。

## 费用与结束状态

本线程累计记录 70 次 API 请求，费用保守占用上界 **3.018332 元**，用户上限20元，内部预留闸门19元。一个历史中断请求保留完整预留额，正常请求按峰时输入未命中价保守计费，实际账单金额未知。[验收时官方费率](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为每百万输入2元、输出8元；以后重跑需重新核对。

测试专用模块已移除，只保留正常 MatPilot 插件。限额仅控制本次测试模块创建的会话，不覆盖用户自行创建的其他对话。API 密钥、账户文件和原始私人日志不在仓库内。
