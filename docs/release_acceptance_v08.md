# dev8 指标筛选与桌面验收

版本：Python 0.2.0.dev8 / Harness 包 0.2.0-dev.8。日期：2026-10-23。

本轮补通逐版本指标从读取、选择到筛选和报告的操作路径，并修正采样上限与默认数量。所有运行使用 CPU 固定样本与明确标记的合成指标，没有调用 LLM、真实材料模型或性质评价器。旧版本、原始对照与负面结果均保留。

## 本次完成

- screen_candidates 和 build_report 接受显式任务、候选、结构版本、指标身份；九工具数量不变。默认多指标仍返回 unknown，不自动挑选有利值。
- 已选和未选指标都保留；非默认报告按选择哈希独立保存，默认报告不被覆盖。单次 pass/fail 只适用于所选证据，不等于材料总体合格。
- v1.1 首版 max_samples 限制为整数 1–32；默认采样量和批量随当前上限收敛。显式超限输入仍被阻止。
- 候选 v2 的 36 题、合成情境、修订说明、空白审核字段及哈希清单已打包。用户后续审核，未代填签名、审核意见或分数。

## 插件提升与证据边界

[完整工具对照](version_metric_tools.md)使用相同 ZIP、CIF 和合成指标字节：dev7 无法把明确指标选择传入筛选和报告，dev8 能完成这条路径；候选数量和采样扣额均为 1，没有追加采样。三份报告从旧版仅一份未知结果，变为保留默认未知及两种明确选择结果。

这是可复现的软件流程改进。既有 [U/U+/M 开发对照](study_plugin_effects.md)与[消融结果](study_ablation_results.md)未证明 M 具有整体耗时或成本优势，当前不增加付费试验寻找正面结果，不宣称 AI 正确率、人工用时或材料性能提升。
