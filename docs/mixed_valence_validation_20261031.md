# 混合价态优化与跨体系留出验证（2026-10-31）

核心版本 0.2.0.dev11。此核心版本与此前部署套件的 dev11 标签属于不同版本轴。

## 实现

自动策略对单注册阴离子和正价态金属阳离子体系使用 ionic_mixed_valence_v1。阴离子包括 O/F/Cl/Br/I/S/Se/N；阳离子采用所安装 pymatgen 的 ICSD 正价态目录，无可用条目时回退 common 正价态。按原子数进行整数动态规划，允许同一元素混合价态，返回逐元素各价态数量的守恒 witness。不支持的体系明确回退 structural_v1。旧 fe_ni_o_relaxation_v1 保留且实现文件未改。

检查输出区分 feasible、no_solution、unknown、unsupported、invalid_input；模型无解与预算耗尽均不能解释为材料物理上不存在。最多1000原子、目标电荷10000、200万候选状态转移和4MiB保存位集，调用者只能降低预算。保留现有结构检查；密度和体积仅作描述。

## 预先固定的验证

原42个Fe-Ni-O结构是开发/回归集。另从Alexandria PBE的12个固定精确元素体系枚举全部ID，按固定SHA256排序每组最多40条，共473条；Fe-Ni-S为33条，其余11组各40。没有ID交集、排除、补样或按性能选择；数据是DFT弛豫结构，不是实验性能样本。

体系为 Fe-Co-O、Co-Ni-O、Fe-Mn-O、Mn-Ni-O、Li-Fe-O、Li-Mn-O、Li-Co-O、Li-Ni-O、Li-Fe-F、Na-Mn-F、Fe-Ni-S、Li-Ca-N。规则、代码、脚本、匿名结构清单先冻结，真实Service执行后才关联独立标签；预测进程运行时拒绝读取标签和原始属性响应。旧版和新版源码快照均不含字节码缓存。

主标签为 E_hull <= 0.1 eV/atom。每组先请求20个；新版不足时不补齐，再按每组实际输出数重跑旧版，匹配名额合计221个。

本批命中增加31个，即14.027个百分点；12组差值均为正。预定体系级单侧符号翻转名义p=0.000244，但所选体系共享元素且不是独立随机总体，不能据此宣称普遍优势。随机10000次的95%选择区间为112-131，它不是总体置信区间。

按每组请求20个的原预算：旧版输出240、命中116；新版输出221、命中139，存在19个输出名额不足。匹配名额主比较与原预算描述必须区分。

## 混合价态的作用和局限

同一新版ICSD价态表的统一价态消融优先池214个，保留138/257低凸包距离结构；允许混合价态后为335个、保留233/257。新增121个中95个低凸包距离、26个较高。这个门槛改进是相对统一价态消融，不是相对跨体系旧生产auto；后者仅作结构推荐、原本接纳全部473个结构代表。

新版仍把24个低凸包距离结构转入人工复核（Li-Ca-N占13个）；另94个低凸包距离结构因名额/覆盖排序未进入最终清单，总漏选118个。无解仅指固定阴离子和有限阳离子价态模型内无解。过氧化物、混阴离子、金属成键等可能超出模型。

原开发集Fe3Ni3O8和FeNi5O8由人工复核恢复进入优先池，但仍未进入开发集Top-20；不能声称两个案例的最终漏选已解决。

同221名额下，新版总输入原子数4270，旧版3646；各体系组成覆盖数之和167 vs 205，空间群覆盖数之和191 vs 206。命中提高带来覆盖与规模取舍，未测得计算时间或费用节省。E_hull<=0.05时命中71→95；严格E_hull=0时6→9，均为预定次要描述。

## 工程验收与复现

323项回归中314通过、9依既有条件跳过，无失败。包含13项求解器专属测试、54个小组成与独立穷举核对，以及Service/CLI/真实FastMCP接口验证。离线复跑新旧与匹配预算后，82项逐候选语义、选择集合及科学指标核对全部一致。
