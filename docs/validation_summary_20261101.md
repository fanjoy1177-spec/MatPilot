# 2026-11-01 验证摘要

源码 core 0.2.0.dev14 合并了两条开发工作；默认排序仍为 ionic_mixed_valence_v1。可选启发式不替换已有可比性质证据。安装包 Harness 0.2.0-dev.12 与 core dev14 是两个版本轴。

## 软件验证与科学证据分开

整合源码的完整 Python 回归为437项：427通过、10跳过（9项仅Linux/WSL，1项可选旧开发数据parity）。正式源码另做32项接口验收全部通过，包含真实MCP冷启动首轮推荐。新100结构离线生产复现的418项语义检查与100项指标合法性检查全部一致。

## 固定100结构的排序趋势

在预先固定的100个WBM候选中，按参考DFT凸包距离确定真实前50名，再看推荐Top20命中数。样本按固定哈希选取，排除了本插件既往实验的ID、化学体系和初始原型族；这不证明与上游模型训练集完全无重叠。

| 方法 | 命中真实前50名 | Precision@20 | 证据边界 |
|---|---:|---:|---|
| 预声明主方法：Wrenformer初始原型归档预测，经实际Service与生产排序组件 | 11/20 | 55% | 仅略高于随机期望，不足以证明可靠筛选提升 |
| MACE归档标量对照 | 20/20 | 100% | 上游经过计算的档案对照；收敛状态未知，未注册为可用Service指标 |
| 同池随机期望 | 10/20 | 50% | 固定100池的描述性基线 |

MACE结果支持“已有外部计算证据可为后续计算优先级提供有用信号”这一条件性判断；它不是主方法结果，也不是插件改进预测器物理精度。插件使用的生产标量顺序与直接采用相同档案数值的排序相同。本轮未进行新的材料模型推断、几何弛豫或DFT。100体系各1条，不能据此证明单体系去重或所有材料类别的普遍提升。

前一轮独立C跨体系研究中，复杂度启发式141/226、旧规则121/226，但大晶胞简单基线154/226更高，未达到全部预声明部署条件；因此保持旧默认，报告保留失败条件。
