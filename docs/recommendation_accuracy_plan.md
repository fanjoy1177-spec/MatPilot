# MatPilot 推荐准确性提升方案

更新：2026-11-01。状态：dev13 隔离版本已接入通用逐结构检查与性质证据排序，跨材料归档预测留出对照已完成；本机 Harness 默认连接及公开发布另行验收。本文件保留最初方案，并在文末记录后续验证。

## 目标与范围

在相同推荐名额或实测计算预算下，优先保留更多满足研究目标的候选，同时降低误删。材料组成不限定为 Fe-Ni-O；当前统一输入对象是带可追溯身份的周期性晶体结构。Fe-Ni-O 的旧结果仅用于问题定位和回归。

准确性分开衡量：输入有效性检查、低凸包能候选命中率、后续计算可完成率、具体应用性质达标率。后三者不相互替代。低力不等于稳定；可配平不等于稳定；多样性不等于质量。

## 通用架构

| 层 | 实现内容 | 适用性与失败处理 |
|---|---|---|
| 结构与身份检查 | CIF/哈希/版本、原文组成约束、占位状态、周期性几何 | 支持的输入格式通用；满占位是当前任务策略，不把无序结构说成不存在；超范围进入复核 |
| 材料类别与规则路由 | 按可解释的规则和显式适用范围选择策略 | 离子电荷检查仅用于适用体系；金属/合金、共价、分子或多孔体系不强套离子规则或统一密度阈值；不确定保留未知 |
| 逐结构质量检查 | 先评估每个结构，再按风险与证据在等价组内选代表 | 几何归一匹配不意味着能量或后续计算价值等价；保留全部被折叠结构和理由 |
| 可替换性质预测器 | 通过适配器输出能量/力/应力或任务指定性质 | 模型必须声明元素、结构类别、参数、权重身份和验证范围；能量势模型不自动提供带隙/离子电导等性质 |
| 任务排序 | 目标达标证据、风险与可信度优先，再做多样性和预算约束 | 无可比证据时只输出结构/计算准备度推荐，不能伪造稳定概率 |
| LLM 与交互 | 理解意图、核对条件、选择适用工具、解释推荐及证据缺口 | 数值来自已核验的工具；不让 LLM 凭语言印象给晶体打物性分 |

## 已找到的具体改进

1. 旧统一价态硬门槛会漏掉混合价候选。已有独立混合价分支推进多体系验证，本工作不改动该分支冻结协议或读取其封存标签。
2. 旧 Fe-Ni-O v1 先去重再分级会误删：正常 P001 与体积扩大8倍的同构工程副本被 scale=True 视为同组；编号优先使异常副本先成为代表。旧流程最终没有推荐，正常结构单独却为优先。仅更换编号就改变是否有结果。修复原型改为可注入通用分级器的逐结构检查与代表选择；元素不硬编码。
3. 目前覆盖排序不会区分同一优先池中真实性质的差异。应加入性质证据后再谈科学排序精度，而不是继续调组成/空间群覆盖权重来承诺准确率。

## 性质证据接入顺序

第一阶段复用现有 candidate_id / structure_version_id / SHA256 / method / reference_set / raw_output 验证机制。新性质记录增加预测器的适用范围、训练数据标识、原始/弛豫版本和不确定性来源。缺失保持 unknown，不把多个模型的分歧直接叫校准置信度。

第二阶段准备 MatterSim 或 CHGNet/MatGL 的独立预测适配器；版本和权重锁定，独立环境运行，默认不自动下载/调用。单点能量、力和应力可作为计算准备度或模型风险线索，不能直接替代凸包距离。跨组成稳定性排序必须使用同方法、同参照和兼容修正的形成能/相图证据；未经参照处理的总能量或每原子能量不跨组成排名。同组成相对能量也不能当作合成成功证明。

第三阶段有独立标签后校准排序。多样性作为同等质量下的次级目标；必要时提供明确标为探索的候选名额，不能混入高置信推荐夸大准确率。模型超出验证范围时输出建议补证据，避免过度自信。

## 验证与验收

- 先冻结算法、适用范围、预算、模型权重和数据拆分。旧42条已用于找问题，不能作为新策略独立验收。
- 已有混合价分支规划12个体系、目标473条独立候选；这是该分支的冻结测试，不在中途加本分支规则或根据标签调参，也不将其视为覆盖所有材料类型。
- 新一轮性质排序测试同时覆盖离子晶体、金属/合金、共价半导体等实际受支持类别；按体系和结构族拆分，检查训练重叠，避免相同原型的轻微变体泄漏。
- 主指标：同名额 Precision@K 和 Recall@K；同时报告优先池召回、被误删好候选、未知/不支持率、输出不足和每体系结果。预算不足的结果也保留，不能只统计成功子集。
- 比较随机、最小规模、仅结构/多样性、仅化学规则、加入预测证据的版本；只在共同输入与同等预算下比较。宏平均与逐体系结果并报，不让大体系掩盖小体系退化。
- 若验证稳定性，以独立 DFT 凸包距离为代理指标并声明阈值与误差；若验证弛豫成功率，需要未弛豫输入及独立的后续收敛结果，不能用已弛豫的数据库结构替代。
- 性能改进须在未用于选模型或调参的数据上重现；仅修复工程反例只能证明不再因检查顺序误删。

## 本轮执行边界

本轮只核查已有数据、编写通用流程实验修复与CPU软件测试。未进行新生成、弛豫、DFT、势能模型推断或付费API。正式业务接口正有另一条混合价开发分支，实验修复单独保存，合并时需要重新登记新策略、冻结源码并回归；不能混入正在进行的盲测。

## 本轮已经完成的工程验证

通用实验模块位于 `.work/recommendation-accuracy-20261031/triage_first.py`，要求显式传入分级策略和适用范围，不设置 Fe-Ni-O 默认。11项软件测试全部通过，包括非Fe-Ni-O的NaCl合成控制信号、未知回退、身份/校验值错误、重复ID、显式选择限制及代表优先规则。

同一工程反例：旧v1未推荐任何结构，新通用流程复用同一旧分级器后保留正常结构B_original；未重新调化学阈值。修复前后记录在该目录 `triage-first-old-new-comparison.json`，测试在 `triage-first-unit-validation.json`。这证明修复了检查顺序造成的漏选，不证明跨体系物性排序已改善。该原型尚未合并到正在验证的生产接口，以保持另一分支已冻结的盲测独立。

## 2026-11-01 留出验证增补

本轮不限定 Fe-Ni-O。已冻结的公开 WBM 归档预测回放包含 163 条留出候选；4 个单例不用于排序效果汇总，余下 159 条、20 个体系。按每体系固定 25%（至少1个）共请求37个推荐，接入固定 MACE 预测与独立 MP 凸包参照后的性质排序命中34个低凸包能候选，初始原型覆盖近似基线命中27个。对应 Precision@requestedK 为91.89%和72.97%，召回率31.19%和24.77%。逐体系6个改善、14个持平、0个退化；共同实际名额36时为33对27。独立重算5,944项无差异。

这些数据支持采用有身份和参照的性质证据辅助优选；插件标量顺序与直接 MACE 排序完全相同，未证明新的物理预测能力。共价代理类可评价8条均无低凸包能正例，无法证明该类发现能力；另外4条单例保留但不计入提升。类别由组成规则定义，并非已实测键合/导电分类。档案中的部分模型预测经过上游ML弛豫，本轮未进行新生成、模型推断、弛豫或DFT；也不是新MatterGen候选的完整CIF端到端试验。推荐原子数总和340，覆盖基线302，同名额不等于同计算费用。

协议、冻结预测、逐体系结果和独立审计位于项目镜像 `.work/cross-material-validation-20261031/coverage-v3/`。留出集已经开封，之后不得用它调参并继续声称为新盲测。已实现的真实软件接口和数据契约见 `recommendation_v2.md` 与 `property_predictor_contract.md`。
