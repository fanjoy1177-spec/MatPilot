## 插件作用的现有证据

[贡献与证据对照表](contribution_and_evidence.md)是作品说明入口；[12 题完整开发对照](study_plugin_effects.md)与[四题开发消融](study_ablation_results.md)保留有利、不利和共同成功的案例。

现有数据支持候选数量/去重核验、条件冲突的明确解释、指标不可比判定等工程作用。r3 的 M 总体耗时与费用高于 U/U+；消融的完整插件费用较低但墙钟较高。尚不能宣称整体提速、正确率提升、人工时间节省或材料性能提升。

本线程累计 API 保守上界为 **22.273968 元**，包含历史保留预占 **2.113536 元**；已提醒超过 20 元。20 元为提醒线。本轮生产修复仅使用固定结构和 CPU 进程，不追加 API 调用或真实材料计算。
