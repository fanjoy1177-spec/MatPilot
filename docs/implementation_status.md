## 证据解释

CPU 回归只证明指定输入下的行为。用固定样本、测试用指标或回放数据测试，不算真实材料生成、科学性质评价或 AI 提升证据。真实模型、正式对照和外部复核未完成前，不将目标标记为全部达成。

指标导入是供受信任的操作员/评价器使用的 Python 接口，没有增加任意文件导入的 LLM 工具。哈希证明文件身份，方法元数据证明记录了什么；它们不能单独证明上游方法声明正确或科学结论可靠。

最新 CPU/协议结果见记录中的实际计数；证据见 `artifacts/v11-unit-validation.json`。该文件记录受测源码哈希。已安装的 0.1.1 固定到独立目录，开发源码为 0.2.0.dev4；旧版 ZIP 不覆盖。
