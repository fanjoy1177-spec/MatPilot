## 2026-10-23 的 dev8 收尾

当前源码为 dev8，保留已发布 dev7、dev6 和既有研究原始数据。dev7 已补齐正式九工具的逐版本指标读取与显式比较；dev8 将明确选择的指标接入原始生成版本的筛选和报告，保留未选择证据，并将不同选择的报告分别存档。多条指标未明确选择时仍为 unknown，不自动挑选有利值。实际前后行为见[同数据 dev7→dev8 对照](../artifacts/metric-screening-cpu-comparison.json)。

dev8 同时将配置采样上限限定为整数 1—32；未指定数量时采用 min(16, 当前上限)，未指定批次大小时采用 min(2, 当前上限)，避免小预算配置被默认值阻塞。显式超额请求仍拒绝，不暗中截断。三处题目歧义仍是候选 v2 提案；原草案与历史数据保留，未批准、未正式封存。详细修订见[题目修订提案](candidate_revision_proposal_v2.md)。

## 插件作用的现有证据

[贡献与证据对照表](contribution_and_evidence.md)是作品说明入口；[12 题完整开发对照](study_plugin_effects.md)与[四题开发消融](study_ablation_results.md)保留有利、不利和共同成功的案例。

现有数据支持候选数量/去重核验、条件冲突的明确解释、指标不可比判定等工程作用。r3 的 M 总体耗时与费用高于 U/U+；消融的完整插件费用较低但墙钟较高。尚不能宣称整体提速、正确率提升、人工时间节省或材料性能提升。

dev7→dev8 的合成数据对照中，原筛选/报告接口不能显式选择指标；新版选择 1.1 时返回 pass，选择 1.6 时返回 fail，未选择时仍 unknown。三种报告同时保留，候选数量与采样扣额均保持 1。它证明所选证据能够进入检查和报告，不证明 AI 会选对指标；pass 也仅适用于明确选择的方法和指标。

本线程累计 API 保守上界为 **22.273968 元**，包含历史保留预占 **2.113536 元**；已提醒超过 20 元。20 元为提醒线。本轮生产修复仅使用固定结构和 CPU 进程，不追加 API 调用或真实材料计算。
