## 与旧入口的对比

| 操作 | 旧桌面接入 | 当前原生插件 |
|---|---|---|
| 找到 MatPilot | 插件列表无独立卡片 | 已安装插件中直接选择 |
| 填写连接路径 | 编辑 YAML 中 MCP 配置 | 在表单中填写并保存 |
| 停用/恢复工具 | 修改/恢复 MCP 配置 | 列表或详情中的开关 |
| 参数保存检查 | 手动检查 YAML | 表单提示，并可查询能力确认连接 |
| 材料流程能力 | Python dev8 的九工具 | 同一套九工具与固定样本结果 |

这证明安装、配置和管理入口得到改善。没有测量新用户操作时间，不报告减少多少步骤/百分比，不把界面改进当作 LLM 推理能力、整体研究提速或材料性能提升。历史同题正反例保留在 [插件效果记录](study_plugin_effects.md)。

## 过程中遇到的问题

- 初版 dev9 未声明实时字段，导致配置表单无法读取；dev10 已修复并实测保存。
- 临时辅助模块内的首次安装触发 HMR 嵌套错误；最终通过正式页面安装及启用。
- 同一路径覆盖同版本 tgz 未更新依赖；改用独立 dev10 文件后正式页面安装成功。
- 保存/启用后工具有重连间隙；首次能力调用曾发生 30 秒 SDK 超时，随后再次调用成功，最终 demo 闭环通过。记录保留失败，不宣称每次首次连接都无延迟。若首次查询超时，确认插件处于启用状态，稍候重试能力查询，再提交任务。

本轮验证覆盖原生入口、配置持久化、启停生命周期与一个固定样本流程；未执行新的真实 LLM 对照、GPU/DFT、第二模型真实推理或正式用户实验。
